# IT Tickets Analysis Dashboard – Power BI Project

## Project Overview
This Power BI dashboard analyzes IT help desk tickets and provides business insights 
through interactive visualizations and KPIs.

The dashboard helps organizations monitor:
- Ticket priorities
- Severity levels
- Department performance
- Resolution efficiency
- Business unit activity

---

## Dashboard Features
- KPI Cards for Total Users, Tickets, Departments, and Resolution Days
- Ticket Distribution by Severity
- Priority Analysis
- Ticket Type Analysis (Issue vs Request)
- Business Unit Comparison
- Department-wise Ticket Monitoring
- Gender-based Ticket Analysis
- Interactive Filters and Slicers
